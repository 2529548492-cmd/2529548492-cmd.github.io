截图解释

框住屏幕上看不懂的地方，AI 把里面的词/概念讲成大白话。Windows 绿色版，免安装。

线路 A · 推荐国内直连（交换站镜像）从云电脑直接下载，国内网络首选（29 MB zip）线路 B · 备用GitHub Releases海外节点，线路 A 打不开时再用（29 MB zip）

zip 里是 截图解释.exe + 使用说明.txt，解压即用；不用装 Python，不写注册表。

怎么用 ​

  1. 解压后双击 截图解释.exe
  2. 第一次会弹「填写 DeepSeek API Key」：去 platform.deepseek.com/api_keys 生成一个 Key（形如 sk-xxxx），粘进来点保存
  3. 屏幕右上角出现蓝色小圆钮「释」，就绪
  4. 点它或按 Ctrl+Alt+Q → 拖动框选看不懂的区域 → 旁边弹出解释卡片
  5. 卡片底部可以继续追问；Esc 关卡片；右键小圆钮退出

功能特点 ​

  • 框选即问：截图只在你框选时发生，不后台偷拍
  • 讲人话：面向完全外行，先一句大白话定义，再打生活比方，术语当场解释
  • 可以追问：卡片里接着问，上下文保留
  • 绿色免安装：单个 exe，删文件夹就干净

说明 ​

  • 系统要求：Windows 10 / 11（64 位），体积 29 MB
  • 需要自备 DeepSeek API Key（模型 deepseek-flash），配置存在 exe 同目录 config.json
  • 截图只发往你自己配置的接口，不经过第三方服务器
  • 杀毒软件可能对打包 exe 误报，加信任即可
