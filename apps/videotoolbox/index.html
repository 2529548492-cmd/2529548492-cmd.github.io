视频工具箱（绿色版）

视频工具箱 · 绿色版

解压即用的视频下载工具箱：把链接粘进去就能下 B 站 / 抖音 / YouTube / 小红书，还能把视频转成文字。内置 Python 和 ffmpeg，什么都不用装。

线路 A · 推荐国内直连（交换站镜像）从云电脑直接下载，实测 300+ KB/s，国内网络首选（86.5 MB）线路 B · 备用GitHub Releases海外节点，国内速度看网络；线路 A 打不开时再用（同一个包）

两条线路是同一个压缩包（86.5 MB）。哪条快用哪条，装一次就够了。

怎么用 ​

  1. 下载后完整解压（别在压缩包里直接双击）
  2. 双击「启动.cmd」
  3. 浏览器会自动打开界面，把视频链接粘进去，点开始

能下什么 ​

B 站 / 抖音 / YouTube / 小红书 / 其他 yt-dlp 支持的站点（随工具更新而扩展）。

需要装别的东西吗 ​

什么都不用装。 Python 运行时和 ffmpeg 都已经打包在文件夹里了，绿色版删掉文件夹就等于卸载。

只有用「转文字」功能时，程序会提示你按需下载语音识别引擎和模型（几十 MB 到几 GB），不下也完全不影响下载视频。

关于代理 ​

不用装 Clash。程序会自动读取 Windows 的「系统代理」：你平时用什么代理软件（Clash / v2rayN / sing-box / 机场客户端）都行，只要它开了系统代理，程序就自动使用；国内站点一律直连。

数据存在哪 ​

  • 程序本体：就在解压出来的文件夹里（绿色，删掉即卸载）
  • 下载的视频：默认在你的「视频」文件夹下的「视频工具箱」里

出问题了 ​

先跑一次目录里的 doctor.py（或看启动时窗口里的提示），它会告诉你缺什么、怎么补。
