硝子聊天助手

硝子聊天助手

在聊天 App 旁边读消息，给出意图判断和三条候选回复。发送始终由你手动点。

线路 A · 推荐国内直连（交换站镜像）从云电脑直接下载，实测 300+ KB/s，国内网络首选（8.6 MB）线路 B · 备用Cloudflare 全球 CDN海外节点，国内部分网络较慢；线路 A 打不开时再用

两条线路是同一个安装包（8.6 MB）。哪条快用哪条，装完不需要都下。

最新版本：1.10 · 修截屏失败 ​

更新时间：2026-11-20

  1. 一键 DeepSeek 模式：判断 / 回复 / 识别三条链路全部走 DeepSeek，完全不调用 Jev
  2. 双击悬浮球（App 图标）立即开始截屏识别，带脉冲动效 + 震动反馈 + 实时秒数
  3. 新增「军师模式」：内置 124 篇沟通知识库，BM25 检索后再给建议
  4. 新增关系描述、回复档位（稳健 / 会撩 / 强势）、聊天记录导入
  5. 微信 / QQ / X / 飞书 / WhatsApp 支持截屏识别（视觉模型转写，能分辨谁说的）
  6. 修复会话标题抖动导致候选回复突然消失的问题

怎么用 ​

  1. 打开 App，开启无障碍服务和悬浮窗权限
  2. 进设置，打开「⚡ DeepSeek 模式」，填 Base URL / 密钥 / 模型（一次搞定三条链路）
  3. 打开任意聊天窗口，双击屏幕上那个App 图标小球
  4. 3~20 秒后出判断和三条候选，点「填入」写进输入框，自己按发送

功能特点 ​

  • 只在你点的时候读屏并请求：不轮询、不自动分析、绝不自动发送
  • 判断 / 回复 / 识别都可换接口：任意 OpenAI 兼容地址都行（DeepSeek、通义、OpenRouter…）
  • 军师模式：情绪落地 → 事实拆分 → 利益判断 → 明确建议 → 行动收束
  • 聊天记录导入：存在本机，分析时自动带上最近上下文
  • 隐私：聊天内容只发往你自己配置的接口，不经过任何第三方服务器

系统要求 ​

  • Android 11 及以上
  • 体积：8.6 MB
  • 需要权限：无障碍服务（读聊天窗口文字）+ 悬浮窗（显示分析卡片）

在第三方聊天 App 里使用可能不符合其用户协议，账号有被限制的风险，请自行判断。
